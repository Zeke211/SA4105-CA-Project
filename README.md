## My Contributions I acted as the lead developer for the Checkout Micro-service, implementing two core features:
1. Stripe Payment Integration
* Implemented end-to-end payment processing using the Stripe API.
* Managed secure session handling and payment success/failure callbacks.
2. Dynamic Discount System
* Built a custom validation engine that cross-references user input against the database.
* Logic Flow: Checks code existence → Validates expiry/usage limits → Applies percentage/fixed deduction →Updates total price dynamically.
* Error Handling: Provides real-time feedback for invalid or expired codes.
## Tech Stack
* Language: Java
* Frontend: Thymeleaf/ HTML5
* Database: MySQL
* APIs: Stripe
